# Rural Education Helper – AI Chatbot

This is a web-based chatbot project developed during my academic internship.  
The chatbot is designed to assist students, especially from rural areas, by answering study-related questions in real time.

The chatbot uses the **Google Gemini API** to generate intelligent responses based on user input.

---

## Features
- Real-time chatbot responses  
- Simple and interactive chat interface  
- Predefined starter buttons for quick questions  
- Typing indicator for better user experience  

---

## Tech Stack
- HTML  
- CSS  
- JavaScript  
- Python (Flask)  
- Google Gemini API  

---

## How It Works
- The user enters a question in the chat box  
- The message is sent to the backend using a POST request  
- The Gemini API processes the input and generates a response  
- The response is displayed in the chat window  

---

## How to Run
1. Clone the repository  
2. Set up the backend using Flask  
3. Add your Google Gemini API key  
4. Run the application and open it in a web browser  

---

## Note
This version of the chatbot supports real-time interaction only.  
Chat history is not stored and will be cleared when the page is refreshed.
