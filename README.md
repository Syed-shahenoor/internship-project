# Rural Education Helper – AI Chatbot

This is a web-based chatbot project developed during my internship.
The chatbot is designed to help students, especially from rural areas,
by answering study-related questions in real time.

The chatbot uses Gemini API to generate responses based on user input.

## Features
- Real-time chatbot responses
- Simple and interactive chat interface
- Predefined starter buttons for quick questions
- Typing indicator for better user experience

## Tech Stack
- HTML
- CSS
- JavaScript
- Gemini API (Backend integration)

## How It Works
- User enters a question in the chat box
- The message is sent to the backend using a POST request
- Gemini API processes the input and returns a response
- The response is displayed in the chat window

## How to Run
1. Clone the repository
2. Set up the backend with Gemini API
3. Add your Gemini API key
4. Run the application and open it in the browser

## Note
This version of the chatbot supports real-time interaction only.
Chat history is not stored and will be cleared on page refresh.
